Connect your agent

Most agents don't write secure code.

Give your agent the ability to find and fix security issues in about a minute. Connect the server, then ask your agent to begin.

On a phone? Open zeroquarry.com/connect on the machine where your agent runs.

1 Add the server — pick your harness

Any MCP-capable harness works — including ones we've never heard of. The fastest path: paste this into your agent and let it wire itself up.

Paste this into your agent
Follow the instructions at https://zeroquarry.com/connect to set yourself up with ZeroQuarry to help me build more secure software.

By hand instead: add a remote MCP server with this URL — OAuth discovery is built in, so a client configured with nothing but the URL finds the sign-in flow on its own.

The server URL
https://mcp.zeroquarry.com/

In the Claude app: Settings → Connectors → Add custom connector.

Name it ZeroQuarry, paste this URL
https://mcp.zeroquarry.com/

One command in any terminal:

Run once — remembered in every project
claude mcp add --transport http --scope user zeroquarry https://mcp.zeroquarry.com/

Then /mcp → ZeroQuarry → Authenticate opens your approval screen. command not found? That's the Desktop app's machine — use the Claude Desktop steps instead.

One click — Cursor opens with the server pre-filled.

Open in Cursor -> Browser asks “Open Cursor?” — choose Allow.

Nothing happened? Paste this in Cursor → Settings → MCP → Add server:

Cursor MCP config
{"zeroquarry":{"url":"https://mcp.zeroquarry.com/"}}

One click — Copilot picks the server up as zeroquarry.

Open in VS Code -> Insiders

Nothing happened? Add it from the terminal:

VS Code CLI
code --add-mcp '{"name":"zeroquarry","url":"https://mcp.zeroquarry.com/"}'

code: command not found? Command Palette → Shell Command: Install 'code' command in PATH, then retry.

One command; saved to ~/.codex/config.toml.

Run once
codex mcp add zeroquarry --url https://mcp.zeroquarry.com/

codex not found? Install the CLI first (npm i -g @openai/codex). On its next connect, approve the ZeroQuarry sign-in in your browser.

2 Ask your agent

Paste this into your harness
Use the get_started tool from ZeroQuarry to help increase my security.

It comes back with a plan — tier, credits, first scan.

What your agent gets — and never gets

Your agent receives a refreshable token scoped to ZeroQuarry's tools: it can start scans, read validated results, and load skills. It never gets your code — on a source scan your repository stays put — and when a scan needs credentials, the zq CLI holds them on your machine while the platform attaches them server-side. Secret values never pass through the model. Fixes arrive as pull requests your agent opens; you review and merge. Nothing merges itself.
